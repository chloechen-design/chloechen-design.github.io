# 新开作品集对话时复制这段

## 新增一个项目

先把项目材料作为附件发在同一个 Codex 对话里，可以分几条消息发，不必预先整理成网站文件。然后贴这段：

```text
我要在现有作品集里新增一个项目：【项目名】。我附上的是这个项目的原始资料和素材。

请先读取仓库里的 AGENTS.md 和 docs/portfolio-redesign-brief.md；如果当前 main 里还没有这些说明，请从作品集说明 PR #13 读取。检查仓库最新正式版本和现有项目页面，然后从最新 main 为本项目开独立分支。

先盘点附件：项目目标、我的角色、真实流程/界面、设计决定、交付和可核实结果分别有哪些证据；缺失的信息标出来，不要编造。然后按已有标准完成这个项目的 case study 页面，并在现有 Work 项目目录增加入口。保留我的网站 foundation；不要重做首页，不要混入 Work 目录的旧草稿或无关文件。给我桌面和手机预览；不要合并或发布，除非我明确说上线。完成后简要说明改了什么、预览在哪里，并更新长期项目状态。
```

## 优化一个已有项目

```text
继续优化我的作品集项目：【项目名】。请先读取仓库里的 AGENTS.md 和 docs/portfolio-redesign-brief.md；如果当前 main 里还没有这些说明，请从作品集说明 PR #13 读取。先检查最新正式页面、项目素材和当前 Git 状态，然后从最新 main 为这个项目开独立分支。只改我点名的项目，按附件/描述中的反馈完成优化，给我桌面和手机预览。不要改首页，不要混入其它草稿，不要编造证据，也不要合并或发布，除非我明确说上线。
```
